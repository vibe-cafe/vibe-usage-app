# Vibe Usage Test 外测说明

这是 Vibe Usage 新外观的外测包。它和正式版分开安装、分开保存界面偏好，不会覆盖正式版。
两者共用同一份 Vibe Usage 账号配置：在外测包里「重新链接」或「重置配置」，正式版也会跟着变。
它不会读取这台 Mac 上其他用户的数据，也不会把订阅配额或诊断日志上传到 Vibe Usage。

## 运行条件

- macOS 14 或更新版本。
- 已安装 Node.js 20 或更新版本，并且 `npx` 可用。外测包用它运行随包附带的同步工具。
- 想看额度的工具（Codex、Claude Code、Kimi Code、Grok、Cursor、Antigravity、OpenCode Go）由你本人安装、登录并用过。ZCode 要在「设置 → 订阅配额 → ZCode」选择区域，填入 Coding Plan API Key 并保存，再打开它的「面板卡片」开关。

## 打开

1. 解压 `VibeUsage-Test.zip`，把 `Vibe Usage Test.app` 拖进「应用程序」。
2. 双击打开。如果系统提示无法打开，到「系统设置 → 隐私与安全性」，点「仍要打开」并确认。

请勿覆盖或删除正式版 `Vibe Usage.app`。

## 新外观

点菜单栏图标打开面板，从上到下三块：

- **订阅配额**：开启两家及以上订阅时，顶部有「概览」和一排圆形按钮。「概览」汇总各家额度，快用完的会标出来；每个圆形按钮是一家订阅，点进去看它的额度圆环，圆心通常是圆环上剩得最少的那个时间窗口。圆形按钮可以拖动排序，最右边的齿轮用来选择要看的订阅。鼠标停在额度行上能看离重置还有多久。
- **近期消耗**：选时间范围，看费用、Token 和活跃时长；可以按终端、工具、模型筛选，模型筛选只影响费用和 Token。点进某一家订阅时，这里只统计这家工具。
- **展开详情**：点面板底部的「展开详情」，看按模型、终端、工具分的分布和 Token 构成。

订阅配额不用登录 Vibe Usage。近期消耗和展开详情要链接数据：正式版已链接的会直接沿用；还没链接时，点「登录并链接数据」，在浏览器核对验证码后确认。

想换回原来的样子，到「设置 → 通用 → 界面样式」选「经典」。

正式版现在也有新外观，同样在「设置 → 通用 → 界面样式」里切换：新装默认新版，从旧版升级的用户留在经典，并在面板上看到一次「要不要试试看」的提醒。外测包没有这条提醒，首次打开默认新版，以后沿用你上次的选择。

## 想请你重点看

- 新外观看得清吗，用起来顺不顺手。
- 数字和你的预期对不对得上，例如今天花了多少、额度还剩多少。
- 有没有显示错位、一直转圈或数字不更新的地方。

## 联网与隐私

每家产品怎么读额度、怎么跟随系统代理、什么时候做出口检测，和正式版相同，逐条说明见 [README 的「功能」一节](https://github.com/vibe-cafe/vibe-usage-app#功能)。简要地说：

- 订阅配额由 App 或同步工具向对应服务商查询，结果只在本机显示，不上传。
- 链接数据时，App 向 Vibe Usage 服务器（默认 vibefriends.com）申请验证码并等待浏览器确认，会附上 App 名称和这台 Mac 的名称。
- 链接后，启动时、点「同步用量」时和每 30 分钟，同步工具会上传用量统计：按半小时汇总的 token 数、模型名、项目名、计算机名和会话时长，以及每 5 分钟里模型在输出的秒数，不含对话、命令和文件内容。上传时还会附上当前界面样式（新版或经典），用来统计两种外观各有多少人在用，正式版也一样；不新增请求。
- 面板读取用量时，用 Vibe Usage 的 Key 向同一服务器查询费用、Token 和去重活跃时长。在新外观里点进某一家订阅、回到概览或更改已开启的订阅时，只有生效的工具筛选变了才会单独重查时长。重置配置解绑后停止查询。打开新面板且当前用量读取成功后，还会向同一服务器一并读取其他几个快捷范围的用量和活跃时长，结果在内存中保留。新面板开着跨过午夜时，会按需补读当前范围。
- 和正式版不同的两点：外测包不检查 App 更新；同步工具由系统的 `npx` 运行，npm 可能按它自己的设置联网检查更新。

## 反馈问题

在「设置 → 关于 → 诊断」的「导出诊断日志」一行点「导出…」，把导出的 JSONL 文件发给测试组织者；界面有问题时，附一张面板截图更好。
日志只记录事件、配额状态（Provider、状态、错误码、计量项数量）和版本信息（App 与同步工具的版本、提交号、构建号，系统版本），不包含路径、账号、Token、Cookie、API Key、响应正文或聊天内容。

不要发送任何产品的凭据文件、浏览器 Cookie、登录二维码、密码或完整终端日志。
