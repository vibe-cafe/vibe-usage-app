# Vibe Usage Test 外测说明

这是 Vibe Usage 新外观的外测包。它和正式版分开安装，界面偏好也分开保存，不影响你正在用的正式版。
它不会读取这台 Mac 上其他用户的数据，也不会把订阅配额或诊断日志上传到 Vibe Usage。

## 运行条件

- macOS 14 或更新版本。
- 已安装 Node.js 20 或更新版本，并且 `npx` 可用。外测包用它运行随包附带的同步工具。
- 想看额度的工具（Codex、Claude Code、Kimi Code、Grok、Cursor、Antigravity、OpenCode Go、ZCode）由你本人安装、登录并用过。

## 打开

1. 解压 `VibeUsage-Test.zip`，把 `Vibe Usage Test.app` 拖进「应用程序」。
2. 双击打开。如果系统提示无法验证开发者，按住 Control 点击它，选择「打开」，再点一次「打开」；仍被拦截时，到「系统设置 → 隐私与安全性」点「仍要打开」。

请勿覆盖或删除正式版 `Vibe Usage.app`。

## 新外观

点菜单栏图标打开面板，从上到下三块：

- **订阅配额**：开启两家及以上订阅时，顶部有「概览」和一排圆形按钮。「概览」汇总各家额度，快用完的会标出来；每个圆形按钮是一家订阅，点进去看它的额度圆环，圆心是剩得最少的那个时间窗口。圆形按钮可以拖动排序，最右边的齿轮用来选择要看的订阅。鼠标停在额度行上能看重置时间。
- **近期消耗**：选时间范围，看费用、Token 和活跃时长；可以按终端、工具、模型筛选。点进某一家订阅时，这里只统计这家工具。
- **展开详情**：点「展开详情」，看按模型、终端、工具分的分布和 Token 构成。

订阅配额不用登录 Vibe Usage。要同步 Token、查看用量，点「登录并链接数据」，在浏览器核对验证码后确认。

想换回原来的样子，到「设置 → 通用 → 界面样式」选「经典」。

## 想请你重点看

- 新外观看得清吗，用起来顺不顺手。
- 数字和你的预期对不对得上，例如今天花了多少、额度还剩多少。
- 有没有显示错位、一直转圈或数字不更新的地方。

## 联网与隐私

- 订阅配额只在本机读取和显示。每家产品怎么读额度、会连到哪里、没检测到代理时怎么处理，与正式版相同，完整说明见 [README](https://github.com/vibe-cafe/vibe-usage-app#readme) 的「订阅配额监控」「单独登录 Cursor」「出口检测」三条。
- 链接数据后，读取用量或切换终端、工具、项目筛选时，App 会按系统代理设置，用 Vibe Usage 的 Key 向同一服务器查询所选周期的去重活跃时长和 AI 工时。在新外观里点进某一家订阅、回到概览（包括重新打开面板）或更改已开启的订阅时，只有生效的工具筛选发生变化才会重新查询时长。重置配置解绑后停止查询。

## 反馈问题

在「设置 → 关于」找到「导出诊断日志」，把导出的 JSONL 文件发给测试组织者；界面有问题时，附一张面板截图更好。
日志只包含时间、Provider、状态、错误码、计量项数量、应用版本与系统版本，不包含路径、账号、Token、Cookie、API Key、响应正文或聊天内容。

不要发送任何产品的凭据文件、浏览器 Cookie、登录二维码、密码或完整终端日志。
